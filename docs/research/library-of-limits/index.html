A library of physical limits takes a strong model from 42 to 47 of 47.

The strongest model we tested still let 5 impossible claims through. Given the ONTO library of limits, it let none through and raised no false alarms.

Frontier model42 of 47
+ ONTO library47 of 47

One square = one impossible claim, 47 in all. Filled: caught and the broken limit named.

47 of 47impossible claims caught with the library
0 of 36false alarms, with and without it
5 vs 0claims only one arm caught: all five with the library (p = 0.06)

How we measured

ClaimsThe same closed 100: 47 impossible, 36 possible, 17 need data.
Two armsThe question alone, or the question plus the library in a sandbox the model can call.
ScoringThe same two blind judges. A catch counts only when the broken limit is named.
CaveatThe frontier model may have guessed it was being tested. Read both arms as a ceiling, not as a typical result.

What it gives

The library is enough to decide these claims when a strong reader uses it. The open work is the reader: small models still have to learn to call it and read the figures right.
